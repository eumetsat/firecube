    Metadata Migration

    This reference covers the types that a plugin imports from firecube.ingestor.api to declare a metadata migration step. A step reads a StoreView and returns a MetadataPlan. To write a step, follow Write A Migration Step.

    Name Description
    MigrationStep A metadata-only migration a plugin declares.
    StoreView A read-only view of a store's metadata, as one metadata snapshot captured it.
    AttributePatch Set and remove attributes of one node.
    MetadataPlan The changes a migration step plans, applied in order.
    ReleaseRecord A named release of a product, bound to one coherent metadata snapshot.
    NodeView The parsed content of one Zarr node.
    ABSENT Marks a key the document does not hold, apart from a null value and from any default.

    Step Contract

    firecube.ingestor.api.MigrationStep

    Bases: Protocol

    A metadata-only migration a plugin declares.

    The executor runs a step once per store under an exclusive claim. It refuses a rerun of the same step at another distribution version.

    Attributes:

    Name Type Description
    id str

    The step's name, unique among installed steps, for example "my-plugin:0.1.0-0.1.1".
    depends_on tuple[str, ...]

    The ids of steps the store must have applied first.
    from_release str | None

    The release the store must be at, or None for any.
    to_release str | None

    The release the executor creates after the step, or None for none.
    descriptive_keys Collection[str]

    Attribute names the step declares descriptive, beyond the built-in list. They cannot make a reserved or interpretation attribute descriptive.

    Examples:

    A step that titles the root group:

    class AddTitle:
    id = "my-plugin:add-title"
    depends_on = ()
    from_release = None
    to_release = None
    descriptive_keys = frozenset()

    def plan(self, view):
        return (AttributePatch("", set={"title": "Daily rainfall"}),)

    Methods:

    plan 

    plan(view)

    Return the changes the step makes to the store view shows.

    Read only view: no I/O, no clock, no randomness. The same view must give the same plan.

    Parameters:

    Name Type Description Default
    view StoreView

    The store's metadata before the step.

    		 required

    Returns:

    Type Description
    MetadataPlan

    The attribute patches, applied in order.

    Plan Types

    firecube.ingestor.api.AttributePatch dataclass

    Set and remove attributes of one node.

    Keys outside set and remove keep their values. A key that set adds goes last.

    Attributes:

    Name Type Description
    node_path str

    The node path, "" for the root group. Leading and trailing slashes are dropped.
    set Mapping[str, Any]

    Attribute names and the JSON values to give them.
    remove tuple[str, ...]

    Attribute names to drop. A name the node lacks is ignored.

    Raises:

    Type Description
    TypeError

    set is not a mapping with string keys, or remove holds a non-string.
    ValueError

    A name is both in set and in remove.

    Examples:

    Set a title on the root group and drop a comment from an array:

    (
    AttributePatch("", set={"title": "Daily rainfall"}),
    AttributePatch("precip", remove=("comment",)),
)

    firecube.ingestor.api.MetadataPlan module-attribute 

    MetadataPlan = tuple[AttributePatch, ...]

    The changes a migration step plans, applied in order.

    An AttributePatch is the only change a plan can hold. Two patches of one node apply one after the other.

    Store View

    firecube.ingestor.api.StoreView

    A read-only view of a store's metadata, as one metadata snapshot captured it.

    The executor builds it from the snapshot it takes before a step plans, so the plan and the run's journal see the same documents. Paths have no leading or trailing slash, and "" is the root group.

    Parameters:

    Name Type Description Default
    nodes Iterable[NodeView]

    The parsed nodes of the store.

    		 required
    release ReleaseRecord | None

    The product's current release, or None when it has none.

    		 required
    now datetime

    The time the executor started the run, timezone-aware.

    		 required

    Raises:

    Type Description
    ValueError

    Two nodes share a path.

    Attributes

    release property 

    release

    The product's current release, or None when it has none.

    now property 

    now

    The time the executor started the run, timezone-aware.

    Methods:

    group 

    group(path)

    Return the group at path.

    Raises:

    Type Description
    KeyError

    No group stands at path.

    array 

    array(path)

    Return the array at path.

    Raises:

    Type Description
    KeyError

    No array stands at path.

    nodes 

    nodes()

    Yield every group and array of the store, sorted by path.

    firecube.ingestor.api.NodeView dataclass

    The parsed content of one Zarr node.

    Every field that reads a key holds ABSENT when the document lacks it. Nothing fills a default.

    Attributes:

    Name Type Description
    path str

    Node path, "" for the root.
    zarr_format int

    3 or 2, from the document kind.
    node_type str

    "group" or "array".
    document Mapping[str, Any]

    The parsed node JSON: zarr.json, .zgroup or .zarray.
    attributes Any

    The v3 attributes value, or the parsed v2 .zattrs.
    dimension_names Any

    The v3 dimension_names, or the v2 _ARRAY_DIMENSIONS attribute.
    fill_value Any

    The array's fill_value. Always ABSENT for a group.
    physical Mapping[str, Any]

    The present storage keys of the format, in document order. Empty for a group.
    extensions Mapping[str, Any]

    The present top-level keys outside the core keys, in document order.

    firecube.ingestor.api.ABSENT module-attribute 

    ABSENT = _Absent.ABSENT

    Marks a key the document does not hold, apart from a null value and from any default.

    firecube.ingestor.api.ReleaseRecord dataclass

    A named release of a product, bound to one coherent metadata snapshot.

    Attributes:

    Name Type Description
    version str

    The release name, kept verbatim. Firecube only requires it to be unique.
    created_at float

    Unix time in seconds when the release was created.
    previous str | None

    The version of the release before this one, or None for the first.
    snapshot str

    The id of the metadata snapshot the release names.
    runs_since_previous tuple[str, ...]

    The ids of the runs recorded since the previous release.
    producer Mapping[str, Any] | None

    The producer identity of the latest run that records one, or None.
    producer_status Literal['recorded', 'unknown']

    "recorded" when producer is set, "unknown" when no run records one.
    note str | None

    The free text given at creation, or None.
    created_by_run str

    The id of the maintenance run that created the release.
    retention Mapping[str, Any] | None

    What the release retains of the chunk bytes, or None when it retains none.
