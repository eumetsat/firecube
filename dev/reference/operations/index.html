    Operations

    The module firecube.operations holds the Python functions that do what the firecube commands do on a finished product. The operations are:

    • Archive and restore a product.
    • Take a metadata snapshot.
    • Adopt a store and migrate its metadata.
    • Create, list, read and verify releases.
    • Rebuild and verify the index record.
    • Preallocate arrays and plan slots.
    • Build multi-resolution levels.
    • Consolidate time coordinates.

    Use this module in scripts, pipelines and tools that manage products from Python. A plugin does not need it, because a plugin imports from firecube.sdk.

    Open a product with open_product, used as a context manager. It gives a Product. Pass the Product as the first argument of an operation.

    The module does not re-export exceptions. Most are in firecube.core.errors. Some are in the runtime module that raises them, for example SlotWindowError in firecube.ingestor.runtime.preallocate. Product.session and Product.manager are internal. Do not use them.

    Opening a Product

    firecube.operations.open_product 

    open_product(
    target,
    *,
    format,
    driver=None,
    product_name=None,
    require_label=True,
)

    Open the product at target and yield its handle for the block.

    The store's recorded label is read before the handle exists, so a refusal writes nothing. When the block ends, also on an exception, the manager the handle built is closed. No storage setting is resolved from the process environment, and nothing is exported to it.

    Name Type Description Default

    The product URI. A string is parsed as a StorageUri.

    		 required
    format str

    The product format, one of zarr, parquet or tensogram.

    		 required
    driver StorageDriverConfig | None

    The storage driver settings. None uses the defaults: fsspec, no endpoint, no credentials.

    		 None
    product_name str | None

    The label the caller expects. A store that records another label is refused. A store that records none opens under this label.

    		 None
    require_label bool

    Refuse a store that records no label. When False, such a store opens under product_name, else under the normalised URI.

    		 True

    firecube.operations.StorageUri dataclass

    A parsed storage location: protocol, authority and path.

    The protocol is file or memory (local) or s3 or gs (remote). The instance is immutable. The constructor normalizes the path and validates the protocol and authority. parse reads a URI string, from_local_path builds a file URI from an absolute path and to_str returns the canonical string. join, parent and with_protocol return storage URI values, and is_remote tells a remote location from a local one.

    Attributes:

    Name Type Description

    The lowercase scheme: file, memory, s3 or gs.
    authority str | None

    The bucket of an s3 or gs URI; None for file and memory.
    path str

    The absolute path, with duplicate slashes collapsed and no trailing slash except the root.

    *,

    Restore a local .zip or .tgm archive into the product.

    The restore holds the product's maintenance claim and records its run as started before it touches the target. On failure it tries to record the run as failed, warns through warn if that fails, and raises the original error either way. An interrupt, KeyboardInterrupt or SystemExit, records no failure: a started run stays started. The call always releases the claim and closes the control plane.

    A zip archive whose marker says incremental is restored with its backup chain: the full backup first, then each incremental backup in order. The whole backup chain is checked before the claim and the run, so a refused backup chain writes nothing to the target.

    A zip archive's marker entry, when present, is checked before the claim and the run. A marker whose mode is full, and an archive without a marker, take the zip restore.

    The product's label must equal the label the archive records, as read_restore_source reads it; an archive that records none takes the product's. The call refuses an archive or a target with another label before the claim, and refuses the target's label again under it. No write replaces the target's label stamp. An unstamped target takes the zip archive's stamp before the claim. The dry run makes the same refusals before the claim and writes nothing.

    product Product

    The open target product, from open_product, under the label to restore.

    		 required
    archive str

    The archive reference the run records.

    		 required
    archive_path str

    The absolute local path of the archive file.

    		 required
    archive_format str

    "zip" or "tensogram".

    		 required
    overwrite bool

    Replace an existing store at the product's URI.

    		 False
    report Callable[[str], None]

    Receives "restored group: <group>" after each tensogram group.

    		 _ignore_line

    		 _ignore_line
    source ArchiveRestoreSource | None

    The archive as read_restore_source read it from archive_path; the call reads it itself when None.

    		 None
    dry_run bool

    Make the refusals from reads only and return the plan; take no claim and write nothing.

    		 False

    Type Description
    ArchiveRestoreResult | ArchiveRestorePlan

    The recorded run id and the restore's summary; with dry_run, the plan.

    Raises:

    Type Description
    ValueError

    archive_format is unknown, or source was read from another path or format; the call reads and writes nothing.
    ProductLabelMismatchError

    The archive or the target records another label than the product; the call refuses it before the claim, or under it before the run, and records no run.
    ProductLabelConflictError

    The archive or an unstamped target holds run records that name several labels; the call refuses it before the claim.
    ArchiveClaimError

    The product's held claims refuse the restore before the claim, the acquisition conflicts, or another owner holds the exclusive maintenance claim; the call tries to record the run as started and failed, once each. The dry run records no run.
    ArchiveConversionError

    read_restore_source or the restore's first checks refuse the archive, or the target holds a store without overwrite; before the claim, or under it before the run, with no run record. Or the restore raises FileExistsError, ImportError or ValueError, or produces no output, and the call first tries to record the run as failed.
    FileNotFoundError

    The archive file does not exist; the call records no run.
    BackupChainError

    A zip marker is unreadable or malformed, the backup chain of an incremental backup is broken or holds a backup with another label, or a local target holds a symlink on a key's path; the call refuses it before the claim and records no run. A backup chain check that fails inside the run raises it after the call records the run failed.

    The sealing markers record who owns the values of a time-coordinate array. firecube zarr preallocate stamps ATTR_PREALLOCATED on grid-valued coordinates and ATTR_COORD_MANAGED on the observed-values coordinates it materializes.
